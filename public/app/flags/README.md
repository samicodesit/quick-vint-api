# Language flag artwork

Unmodified Twemoji flag SVGs, version 16.0.1, by Twitter and the Twemoji contributors.

Source: https://github.com/jdecked/twemoji/tree/v16.0.1/assets/svg

Graphics licensed under CC BY 4.0: https://creativecommons.org/licenses/by/4.0/
The full license is included in `LICENSE-GRAPHICS`.

Files use country codes from the existing AutoLister output-language mapping. They are self-hosted so the language controls render consistent artwork without relying on device emoji fonts or an external image request. Flags are decorative aids; full language names remain the labels.
