Vous avez déjà photographié les vêtements que vous voulez vendre ? AutoLister peut utiliser ces images pour créer deux photos sur mannequin IA, si l’article s’y prête. Vous créez votre mannequin une fois, puis vous le retrouvez pour vos prochaines annonces.

## 1. Choisissez votre mannequin

Ouvrez <strong>Votre mannequin</strong> dans AutoLister. Choisissez le genre, la couleur des cheveux, la taille, la corpulence et le teint. Vérifiez vos choix avant de le créer : vous ne pourrez plus les modifier ensuite.

## 2. Ajoutez vos photos du vêtement

Utilisez des photos nettes du vrai vêtement, avec le dos et les détails importants. Gardez-les dans l’annonce pour que les acheteurs puissent voir les étiquettes, le tissu et les traces d’usure.

## 3. Générez les photos, puis vérifiez-les

Activez <strong>Votre mannequin</strong>, puis générez votre annonce. AutoLister ajoute deux photos sur mannequin si l’article s’y prête. Comparez-les avec vos photos, surtout la couleur, les coutures, les fermetures et les logos. Supprimez celles qui ne représentent pas correctement ces détails.

## L’article est déjà en ligne ?

Avec l’extension, ouvrez votre annonce Vinted en mode modification et choisissez <strong>Ajouter les photos du mannequin</strong>. Le titre et la description restent inchangés. Vous vérifiez et enregistrez vous-même l’annonce.

Votre mannequin reste dans votre compte. Laissez-le activé pour le prochain article ou désactivez-le dans les paramètres.
